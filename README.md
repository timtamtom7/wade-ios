# Wade

An encrypted finance and budgeting app with AI insights.

## What it does

- Budgets
- recurring expenses
- currency
- AI insights
- conversations

## Targets

- iOS

## Structure

Key types:

- ``BudgetService``
- ``RecurringExpenseService``
- ``CurrencyService``
- ``AIInsightsService``
- ``ConversationService``
- ``DatabaseService``
- ``Cipher``

`Cipher` and a `ConversationView`/`MessageBubbleView` pair suggest encrypted chat-style interaction over financial data.

## Status

Apple-platform experiment built to explore what an AI coding agent could produce for a native app. Not actively maintained.
